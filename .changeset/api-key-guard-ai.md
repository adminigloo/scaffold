`mayCallModels(env)`: true only inside the running app (`NEXT_RUNTIME` or `VERCEL` set), or when the owner has set `AI_OWNER_APPROVED_SCRIPT_RUN=yes` for one approved run. Found after agent test scripts on a sibling project built their own provider client from a laptop's `.env.local` and spent the owner's whole monthly budget in about two hours grading test replies — the key pays for a site's own traffic, never for a script, an eval or a coding agent's test harness.
